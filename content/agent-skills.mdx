---
title: Agent skills
description: Give a coding agent the Blux skill file.
---

Install the Blux skill from this repo:

```bash
npx skills add bluxcc/docs
```

Or give your coding agent this URL:

[https://docs.blux.cc/SKILLS.md](https://docs.blux.cc/SKILLS.md)

The agent follows it: install one package, set the App ID, sign the user in, then read and write on Stellar.
