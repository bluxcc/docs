---
title: Get Balances
description: Fetch the balances of a Stellar account using the Blux core SDK.
---

The `getBalances` function returns the balances of a Stellar account. Omit `address` to use the connected account, and omit `network` to use the currently active network. `address` accepts `G…`, `M…`, SEP-2 federation, or `.xlm`; see [address resolution](/javascript/core/address-resolution).

## Type
```tsx
type GetBalancesOptions = {
  address?: string; // G…/M…, SEP-2 address, or .xlm name
  network?: string; // Omit to use the active network
  includeZeroBalances?: boolean;
};

type GetBalancesResult = Horizon.HorizonApi.BalanceLine[];
```

## Usage
```typescript
import { core } from "@bluxcc/core";

const result = await core.getBalances({ address: "alice.xlm" });
```
